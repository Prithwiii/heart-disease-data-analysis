# Heart Disease Data Analysis

## Overview

This project analyzes a heart disease dataset using Python, focusing on exploratory data analysis (EDA), data preprocessing, visualization, supervised machine learning, and unsupervised learning.

The project examines patterns in the dataset, identifies data quality issues, prepares the data for analysis, and compares multiple machine learning models for heart disease classification.

## Objectives

* Explore the structure and characteristics of the dataset
* Identify missing values and data quality issues
* Analyze numerical and categorical features
* Examine class distribution and dataset imbalance
* Investigate relationships between features using correlation analysis
* Apply appropriate preprocessing techniques
* Train and compare multiple machine learning models
* Explore patterns using K-Means clustering

## Exploratory Data Analysis

The analysis includes:

* Dataset structure and data types
* Feature and target distribution
* Categorical feature analysis
* Missing-value analysis
* Class imbalance analysis
* Numerical feature scale analysis
* Correlation analysis

## Data Preprocessing

The preprocessing pipeline includes:

* Handling missing values
* Removing unnecessary columns where appropriate
* Imputing missing categorical and numerical values
* One-hot encoding categorical variables
* Feature scaling
* Train-test splitting

## Machine Learning

The project evaluates several supervised learning approaches:

* Logistic Regression
* Gaussian Naive Bayes
* Multi-Layer Perceptron (MLP)

K-Means clustering is also explored as an unsupervised learning approach.

## Model Evaluation

Models are compared using multiple evaluation metrics, including:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
* ROC Curve
* AUC
